# Проект «Портал ВОЕВОДА»

## Общая информация
- Полное название: Портал военно-тактической подготовки граждан «Воевода»
- Заказчик: ООО ВПТЦ «ВОЕВОДА»
- Исполнитель: ИП Калинская М.А. / ARASAKA BUSINESS INC.
- Бюджет: 2 000 000 ₽
- Срок: 18 спринтов × 2 недели

## Технологический стек (утверждённый)

### Frontend
- React + TypeScript
- Vite (сборщик)
- React Router (роутинг)
- TanStack Query (серверное состояние)
- Zustand (клиентское состояние)
- React Hook Form + Zod (формы и валидация)
- Tailwind CSS (стили)

### Backend
- Django + Django REST Framework (API)
- Django Channels (WebSocket)
- Celery (фоновые задачи)
- Redis (кэш + брокер)
- PostgreSQL (база данных)

### Инфраструктура
- Docker + Nginx
- Terraform (IaC)
- S3 / Cloudflare R2 (хранилище)
- GitHub Actions (CI/CD)
- Vercel (frontend deploy)

### Безопасность
- HTTPS / TLS only
- HttpOnly Secure Cookies
- RBAC (ролевая модель)
- Field-Level Encryption
- CodeQL + Dependabot

### Тестирование
- Playwright (E2E)
- Unit tests (frontend + backend)
- Storybook (UI документация)

### Мониторинг
- Sentry (ошибки)
- PostHog (аналитика)

## Принципы разработки
- One feature = One branch = One PR
- Каждый PR → автоматический Preview Deploy
- Обязательные тесты перед merge
- Feature flags для новых модулей
- Security-first подход
- Инфраструктура через код (Terraform)
- Полный мониторинг production

## Ролевая модель (RBAC)
- Курсант — основной пользователь, запись на курсы, LMS, тесты, ДЗ, чаты
- Инструктор — ведёт занятия, ставит оценки, видит отзывы
- Командир — руководит подразделением, доступ к оргструктуре
- QA — контроль качества, доступ к тестовым данным
- Admin — полный доступ ко всем разделам
- Куратор (Mila) — приёмка результатов, просмотр всех данных

## Структура проекта (mono-repo)
- `apps/web` — фронтенд (React)
- `apps/api` — бэкенд (Django)
- `packages/ui` — общие UI-компоненты
- `packages/sdk` — типизированный API-клиент
- `infra` — Docker, Nginx, Terraform, скрипты
- `docs` — архитектура, ADR, онбординг

## Основные разделы портала (ключевые)

### Блок 1. Главная страница и навигация
- Хедер: логотип, поиск по 7 категориям, выбор города, уведомления, избранное, кошелёк, корзина
- Двухуровневое меню (1-й уровень: Мой профиль, Военная подготовка, Путь Воеводы, Сообщества, Военмаркет, Журнал, Каптёрка, Чаты, О компании, Реклама)
- Баннеры и слайдеры (редактируемые через админку)
- Блоки: Преподаватели, Командиры, Наши герои, Лидеры, Журнал, Военная подготовка, Сообщества, Соревнования, Города
- Футер с контактами и документами

### Блок 2. Авторизация и регистрация
- Вход (/login)
- Регистрация (/register) с SMS-верификацией (Россия, Беларусь, Казахстан, СНГ)
- Альтернативный вход: Госуслуги (ЕСИА), ВКонтакте
- Восстановление пароля (/restore) через SMS или email
- Публичные документы (/documents) — 18 разделов

### Блок 3. Военная подготовка
- Каталог курсов (/courses) с фильтрацией по городу, дате, формату, стоимости
- Карточка курса: hover-информация, избранное, корзина, запись
- Серии курсов с условиями доступа (прохождение предыдущего)
- Страница курса (/courses/:slug) — 9 разделов (видео, требования, программа, расписание, отзывы и т.д.)
- Раздел «Город» (/city/:slug) — курсы, сообщества, соревнования, лидеры города

### Блок 4. Корзина и оплата
- Корзина (/cart) с вкладками (все товары / обучение / военмаркет)
- Оформление заказа (/checkout) с выбором потока для курсов
- Интеграция ЮKassa: карты, СБП, кошелёк ЮMoney, Долями
- Подписание договора через SMS (ПЭП)
- Партнёрская программа (3 уровня: 3% / 4% / 5%)

### Блок 5. Личный кабинет
- Личное дело (/profile/:username) — фото, погоны, звание, индекс Воеводы, шевроны, вкладки (Данные / График подготовки / Замеры)
- Редактирование профиля (/profile/edit)
- Избранное (/favorites) — 4 вкладки
- Кошелёк (/wallet) — бонусы + деньги, история, вывод
- Уведомления (/notifications) + модальное окно в хедере

### Блок 6. Мой путь Воеводы (геймификация)
- Страница (/voevoda-path) — визуализация Индекса Воеводы по 5 направлениям
- Физическая подготовка (Тест Купера: бег, плавание, велосипед, силовой)
- Тактическая подготовка (5 критериев, оценка инструктора)
- Командирская подготовка (только для командиров)
- Инструкторская подготовка (5 критериев, включая посещаемость)
- Доп. показатели: тоннаж, коэффициент атлетизма, ИМТ, замеры тела
- Знаки отличия (погоны, шевроны, береты, знаки) — ч/б до получения
- Дипломы, соревнования, достижения

### Блок 7. LMS (обучение)
- Мои курсы (/my-courses) — фильтры, календарь занятий, ДЗ
- Страница курса (куплен) (/my-courses/:slug) — список занятий, прогресс
- Страница занятия (/lessons/:id) — голосование по прибытию, попутки, рапорты, материалы
- Тестирование и экзамены (/tests/:id) — таймер, пропуск вопросов, пересдача
- Домашние задания (/homework/:id) — отзыв об уроке
- Мои учебные группы (/my-groups) — оргштатная структура (полк→батальон→рота→взвод→отделение)

### Блок 8. Учения (/exercises)
- Список учений с фильтрами
- Страница учения: голосование, попутки, рапорты, карта полигона, скрытые задачи
- Итоги учений: победитель, задачи, рапорты, баллы

### Блок 9. Социальная сеть
- Журнал/лента (/journal) — статьи, новости, блог, реакции
- Сообщества (/communities) — как ВКонтакте, с лентой и участниками
- Соревнования (/competitions)
- Чаты (/messages) — WebSocket, групповые чаты, голосовые, файлы

### Блок 10. Маркетплейс
- Военмаркет (/shop) — каталог, фильтры, карточка товара, сравнение, фото-отзывы
- Каптёрка (/kaptorka) — доска объявлений (аналог Авито)

### Блок 11. Дополнительные разделы
- Партнёрская программа (/referral)
- Рекламный кабинет (/advertise)
- Вопросы и ответы (/faq)
- О компании (/about)
- Благотворительность (/charity)
- Техподдержка (/support)

### Модальные окна (полный список)
- Профиль (Данные/Подготовка/Замеры)
- Шеврон (название + условия получения)
- Диплом (просмотр)
- Видео-визитка
- Верификация SMS (регистрация и договор)
- Возьму на борт / Запросить попутку
- Рапорты (подать/запросить)
- Информация о показателе (иконка i)
- Связаться (быстрый чат)
- Запросить замену / Оставить оценку
- Добавить тренировку / Взвеситься / Цель
- Благодарственное письмо (с перелистыванием)
- Уведомления (последние)
- Итоги учений
